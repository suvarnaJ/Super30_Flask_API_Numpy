# Super30 Flask NumPy Calculation API

## Objective

Build a Numerical Analysis API by combining:

- Python
- Flask
- NumPy
- REST GET APIs

The application performs numerical calculations dynamically using NumPy and exposes the results through Flask GET APIs.
